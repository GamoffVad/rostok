# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантическое версионирование](https://semver.org/lang/ru/).
Новая версия выпускается командой `npm run release:patch | release:minor | release:major`.
Каждый раздел описывает изменения по сравнению с предыдущей версией; описание релиза на GitHub собирается из него (`scripts/release-notes.mjs`) вместе со списком коммитов и ссылкой на сравнение.

## [1.4.0] — 2026-09-27

### Добавлено
- Своя библиотека компонентов `src/ui/` — все элементы интерфейса берутся из неё; витрина со всеми состояниями — «Администрирование → Компоненты».
- Поле даты `DatePicker` вместо системного календаря: ввод цифрами по маске дд.мм.гггг (точки ставятся сами) и свой календарь — месяц и год из выпадающих списков, стрелки, PageUp/PageDown, Enter, Esc; дата рождения — не позже сегодня и не раньше 25 лет назад; «Такой даты нет» для 31.02 и подобных.
- Флажок `Checkbox` вместо системного — в контактах, программе коррекции и отчёте для родителей.
- Подсказки в стиле приложения вместо системных (атрибут `title`) — при наведении и при фокусе с клавиатуры.
- `FilePick`: загрузка Excel и резервной копии — в том числе перетаскиванием файла на кнопку.

### Изменено
- Выделение текста, курсор ввода, полосы прокрутки и уголок растягивания поля — в палитре приложения.
- Формы больше не показывают системные всплывающие ошибки проверки браузера.
- Общие компоненты (`Dropdown`, `FilterCard`, `Level`, графики, иконки) перенесены из `src/components/` в библиотеку `src/ui/`.

## [1.3.1] — 2026-09-27

### Изменено
- Форма ребёнка и карточка контакта компактнее и выровнены. Поля ребёнка (ФИО, дата рождения, заключение ТПМПК) — в одну строку.
- Карточка контакта — одна сетка «вид | значение | действие»: роль, вид телефона и адреса, «эл. почта», «примечание» в одной колонке, значения — в другой, кнопки удаления — в третьей; все поля 38 px.
- Пустые строки «Эл. почта» и «Адреса» больше не занимают место: «+ телефон · + почта · + адрес» и «Законный представитель» — одной строкой под контактом.
- Контакты разделены пунктиром вместо толстой линии слева (по дизайн-системе линия толще 1 px — только маркер выбора).

## [1.3.0] — 2026-09-27

### Добавлено
- Раздел «Администрирование» (значок базы в шапке) с вкладками «Данные» и «Словари».
- «Словари»: редактирование всех словарных значений — названия и описания уровней 0–3, формулировки для заключения и для родителей, этапы звукопроизношения, варианты ответов, стратегии сканирования, блоки, разделы, группы проб и пробы, направления работы, итоги коррекционной работы, пороги дефицита, срезы, «Кем приходится», виды телефонов и адресов.
- Правки словарей видны сразу на всех экранах, в отчётах и выгрузках; очищенное поле возвращает значение по умолчанию; словарь можно сбросить целиком. Словари входят в резервную копию.

### Изменено
- «Кем приходится», вид телефона и вид адреса выбираются из выпадающего списка приложения со значениями из словарей (вместо системной подсказки браузера).
- Карточка родителя компактнее и выровнена: подпись слева, значения справа; на телефоне вид контакта и кнопка удаления — над значением.
- Описание релиза на GitHub начинается с «Что изменилось по сравнению с …»: раздел CHANGELOG, коммиты с предыдущей версии и ссылка на сравнение; без раздела в CHANGELOG релиз всё равно создаётся.

## [1.2.1] — 2026-09-27

### Изменено
- Процесс выпуска: описание релиза берётся из CHANGELOG node-скриптом (awk на раннере не находил раздел версии), PDF документации прикладывается к релизу с латинским именем (с кириллицей GitHub переименовывал его в `default.pdf`). Изменений в самом приложении нет.

## [1.2.0] — 2026-09-27

### Добавлено
- Закреплённая шапка с меню: остаётся на месте при прокрутке; на телефоне меню в одну строку с прокруткой.
- Закреплённый футер; справа — версия приложения мелким серым шрифтом, при наведении — дата сборки.
- У каждого родителя и родственника — несколько телефонов (мобильный, рабочий, домашний), несколько адресов (проживания, регистрации) и несколько адресов эл. почты.
- Версия приложения берётся из `package.json` при сборке; команды `release:*`, релизы на GitHub по тегу.

### Изменено
- Лист «Родители» в Excel по ребёнку выгружает все телефоны, почты и адреса.
- Контакты из версии 1.1 (один телефон и одна почта) переводятся в новый формат автоматически.

## [1.1.0] — 2026-09-27

### Добавлено
- Библиотека упражнений по каждой диагностической пробе, шаблон Excel для заполнения и загрузки.
- Программа коррекции ребёнка по дефицитам среза: порог 2–3 или 1–3, свои дополнения к пробе, рекомендации специалиста и родителям.
- Отчёт для родителей только по одному ребёнку: печать / PDF, файл .html для отправки, Excel по ребёнку.
- Контакты родителей и родственников у ребёнка, добавление ребёнка сразу с родителями.

### Исправлено
- Таблица протокола тянется до правого края; пустые ячейки пустые; длинные названия проб переносятся, а не обрезаются.

## [1.0.0] — 2026-09-18

### Добавлено
- Первая версия: группы и дети, обследование (речевой блок и нейродиагностика), протокол группы, динамика с шестью видами графиков, карта ребёнка, черновик заключения.
- Импорт прежней книги Excel «Динамика речевого развития», выгрузка протоколов и динамики в Excel, резервная копия.
- Публикация на Vercel с группой-примером.
