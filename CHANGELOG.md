# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантическое версионирование](https://semver.org/lang/ru/).
Новая версия выпускается командой `npm run release:patch | release:minor | release:major`.

## [1.2.0] — 2026-09-27

### Добавлено
- Закреплённая шапка с меню: остаётся на месте при прокрутке; на телефоне меню в одну строку с прокруткой.
- Закреплённый футер; справа — версия приложения мелким серым шрифтом, при наведении — дата сборки.
- У каждого родителя и родственника — несколько телефонов (мобильный, рабочий, домашний), несколько адресов (проживания, регистрации) и несколько адресов эл. почты.
- Версия приложения берётся из `package.json` при сборке; команды `release:*`, релизы на GitHub по тегу.

### Изменено
- Лист «Родители» в Excel по ребёнку выгружает все телефоны, почты и адреса.
- Контакты из версии 1.1 (один телефон и одна почта) переводятся в новый формат автоматически.

## [1.1.0] — 2026-09-27

### Добавлено
- Библиотека упражнений по каждой диагностической пробе, шаблон Excel для заполнения и загрузки.
- Программа коррекции ребёнка по дефицитам среза: порог 2–3 или 1–3, свои дополнения к пробе, рекомендации специалиста и родителям.
- Отчёт для родителей только по одному ребёнку: печать / PDF, файл .html для отправки, Excel по ребёнку.
- Контакты родителей и родственников у ребёнка, добавление ребёнка сразу с родителями.

### Исправлено
- Таблица протокола тянется до правого края; пустые ячейки пустые; длинные названия проб переносятся, а не обрезаются.

## [1.0.0] — 2026-09-18

### Добавлено
- Первая версия: группы и дети, обследование (речевой блок и нейродиагностика), протокол группы, динамика с шестью видами графиков, карта ребёнка, черновик заключения.
- Импорт прежней книги Excel «Динамика речевого развития», выгрузка протоколов и динамики в Excel, резервная копия.
- Публикация на Vercel с группой-примером.
