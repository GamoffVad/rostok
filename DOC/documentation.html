01Зачем это приложение

Специалист два раза в год обследует каждого ребёнка группы по десяткам проб, сводит результаты, строит диаграммы для отчёта и пишет заключения. «Росток» оставляет человеку только первое — поставить балл.

Что показало изучение практики

Документация педагога-психолога и учителя-логопеда ДОУ включает протоколы обследования, карты развития, журналы учёта, аналитические справки и представления на ППк. Мониторинг проводится минимум дважды в год (сентябрь и май), оценка — балльная (обычно 0–3), результат — сравнение количественных показателей начала и конца года по каждому ребёнку и группе в целом. Нейропсихологическая диагностика дошкольников (Ж. М. Глозман, Т. В. Ахутина) использует ту же логику штрафных баллов: 0 — норма, 3 — выраженное нарушение.

02Анализ исходного файла Excel

Книга «Динамика речевого развития 2022–2023»: 16 листов, 30 строк под детей, два учебных года, по два среза в каждом (НГ — начало года, КГ — конец года).

В приложении принята шкала из «Лист2» (0 — норма), как в нейропсихологической диагностике. При загрузке прежнего файла баллы переводятся автоматически: новый = 3 − старый, стадии звука: 3 → норма, 2 → автоматизация, 1 → постановка, 0 → нарушен.

03Установка и первый запуск

Запуск

npm install установка зависимостей (один раз) npm run dev рабочий режим: http://localhost:5183 npm run build готовая статика в папке dist/ — можно выложить на любой хостинг

Серверной части нет. Требуется Node.js 20+ для сборки; для работы — любой современный браузер.

Стартовый экран

Пока нет ни одной группы, приложение показывает четыре шага и три способа начать: создать группу, загрузить прежний файл Excel или открыть пример с вымышленными детьми.

04Экран «Дети»

Список группы и состояние обследования на выбранном срезе.

  • Фильтры «Группа» и «Срез» общие для всех экранов и запоминаются между сеансами.
  • Добавить детей — два способа: «Один ребёнок с родителями» (фамилия, дата рождения, ТПМПК и сразу контакты родителей и родственников) или «Списком фамилий» — по одной на строку; нумерация вида «1.» или «2)» отбрасывается, поэтому колонку можно копировать прямо из Excel или Word.
  • Родители — колонка показывает, кто из родственников записан; «добавить» ведёт в карту ребёнка.
  • Фамилия открывает карту ребёнка, обследовать — экран ввода. Удаление требует подтверждения в строке.
  • Настройки группы внизу: переименование и удаление вместе с детьми.

05Экран «Обследование»

Ввод по одному ребёнку. Слева — пробы раздела, справа — сводка по блоку и поле наблюдений. Всё сохраняется сразу, кнопки «Сохранить» нет.

Звукопроизношение

Для звука отмечается этап работы: Н норма, Д дифференциация, А автоматизация, П постановка / вызывание, × нарушен. Добавлены звуки раннего онтогенеза из «Лист2». Пустые звуки в расчёт не входят.

Нейродиагностика

13 разделов: общие сведения, профиль латеральной организации (глаз, рука, нога), нейродинамика, стратегия сканирования зрительного поля, память, программирование и контроль, двигательная сфера, гнозис, речь, письменная речь, мышление, ошибки и наблюдаемые симптомы (есть / нет).

06Экран «Протокол группы»

Привычная таблица: дети по строкам, пробы по столбцам. Удобно, когда обследование идёт фронтально или данные переносятся с бумажных бланков.

  • Нажатие по ячейке перебирает отметки по кругу: пусто → 0 → 1 → 2 → 3 → пусто.
  • С клавиатуры: цифра ставит балл и сдвигает вправо, в конце строки — на следующего ребёнка (как Tab в Excel); стрелки перемещают, Backspace очищает.
  • Первая колонка закреплена — при горизонтальной прокрутке фамилии остаются на месте.
  • Выгрузить протоколы в Excel — книга .xlsx: по листу на каждый раздел, с суммой, средним и уровнем.

07Экран «Динамика» и графики

Сравнение двух срезов по группе. По умолчанию — начало и конец последнего года, где заполнены оба среза; любую пару можно выбрать вручную.

Показатели

Три числа под фильтрами: сколько детей обследовано на обоих срезах, средний балл группы с изменением (зелёное — балл снизился, то есть стало лучше) и доля детей с положительной динамикой.

Внизу экрана — аналог листа «динамика 2 года»: уровень каждого ребёнка по разделам на двух срезах (теплокарта), средний балл, изменение и итог. «Выгрузить в Excel» сохраняет её вместе с подсчётом детей по уровням.

08Карта ребёнка и заключение

Профиль и динамика

  • Сведения: фамилия и имя, дата рождения, заключение ТПМПК, заметки.
  • Показатели: средний балл и уровень по каждому блоку на последнем срезе, изменение от первого среза, итог по речи.
  • Графики: радар речевого профиля (первый и последний срез), линия среднего балла по всем срезам, «гантели» по сферам нейродиагностики.
  • Уровни по всем срезам: таблица-теплокарта, в последней строке — сколько проб заполнено.

Заключение

Вкладка «Заключение» собирает текст из баллов выбранного среза: по каждому разделу — формулировка уровня, средний балл, перечень проб, требующих коррекции и находящихся в процессе формирования, для звуков — группировка по этапам работы, сравнение с предыдущим срезом, рекомендации для разделов с уровнем 2–3, итог речевого развития и наблюдения специалиста. Текст правится прямо на странице; кнопки — «Печать», «Копировать текст», «Собрать заново из баллов».

Заключение — черновик, а не диагноз: формулировки и рекомендации специалист проверяет и дополняет сам.

09Программа коррекции и отчёт для родителей

Три связанные возможности: библиотека упражнений по каждой пробе, программа коррекции ребёнка по выявленным дефицитам и отчёт только по одному ребёнку — для встречи с родителями, печати или отправки файлом.

Родители и родственники

У каждого ребёнка — список контактов без ограничения числа. В карточке контакта: кем приходится (выпадающий список: мама, папа, бабушка, опекун…), ФИО, отметка «законный представитель», несколько телефонов с видом (мобильный, рабочий, домашний), несколько адресов эл. почты и несколько адресов с видом (проживания, регистрации), примечание — удобное время для связи, кто забирает из сада. «+ телефон», «+ почта», «+ адрес» добавляют строку, значок корзины удаляет её.

Варианты «Кем приходится», видов телефонов и адресов — словарные значения: их меняют в «Администрирование → Словари». Карточка построена на одной сетке из трёх колонок — «вид | значение | действие»: роль, вид телефона и адреса, «эл. почта» и «примечание» стоят в левой колонке, ФИО и значения — в средней, кнопки удаления — в правой. Все поля одной высоты; «Законный представитель» и ссылки «+ телефон · + почта · + адрес» собраны в одну строку под контактом, контакты разделены пунктиром. На телефоне вид и кнопка удаления стоят строкой над значением. Пустые строки и контакты без ФИО и телефона не сохраняются.

В отчёт для родителей попадают только законные представители и только их имена — без телефонов. Полный список контактов — все телефоны, почты и адреса — выгружается в Excel по ребёнку (лист «Родители»).

Библиотека упражнений

Экран «Упражнения» в верхнем меню. Для каждой диагностической пробы — свой блок упражнений, одна строка — одно упражнение. Слева — разделы со счётчиком заполненных проб, справа — пробы раздела. Разделы без балльной оценки (латеральность, ошибки, симптомы) в программу не попадают, поэтому в библиотеке их нет.

  • Шаблон Excel — выгружает все пробы с кодами и текущими упражнениями. Упражнения вписываются в последнюю колонку, новая строка в ячейке — Alt+Enter. Колонку «Код» менять нельзя: по ней файл сопоставляется с пробами.
  • Загрузить из Excel — обновляет пробы с заполненной ячейкой; пустые ячейки ничего не стирают.
  • Вернуть образцы / очистить всё — в приложении есть образцы упражнений для речевого блока и части нейродиагностики; их можно заменить своими или удалить.

Программа коррекции

Вкладка «Программа коррекции» в карте ребёнка. Программа собирается автоматически по выбранному срезу:

  • дефицит — проба с баллом не ниже порога: «уровень 2–3» (нужна коррекция) или «уровень 1–3» (включая формирующиеся); звуки — все, кроме нормы; стратегия сканирования — если не сформирована;
  • пробы сгруппированы по разделам; у раздела — средний балл, уровень и направление работы;
  • к каждой пробе подставляются упражнения из библиотеки; снятая отметка исключает пробу из программы;
  • «+ дополнить для этого ребёнка» — свои упражнения, дозировка, материал только для этого ребёнка;
  • внизу — два поля: «Рекомендации специалиста» и «Рекомендации родителям (занятия дома)».

Всё сохраняется сразу, отдельно для каждого среза: программа на начало года и программа на конец года не смешиваются.

Отчёт для родителей

Кнопка «Отчёт для родителей» в карте ребёнка открывает режим показа: навигации по приложению нет, на странице только данные этого ребёнка — экран можно повернуть к родителям. Вверху выбираются срез, срез для сравнения и состав отчёта: речевое развитие, нейродиагностика, результаты по пробам, программа коррекции, рекомендации.

Правила адаптивности

  • Зоны касания не меньше 44 px: отметки, строки списков, вкладки, кнопки; на компьютере они уплотняются до 34 px.
  • Поля ввода на телефоне набраны 16 px — мобильный Safari не масштабирует страницу при фокусе.
  • Навигация переносится на вторую строку, ничего не прячется в «гамбургер».
  • Двухколоночные экраны складываются в одну колонку ниже 1024 px; фильтры встают столбцом ниже 768 px.
  • Графики измеряют ширину контейнера и перестраивают оси — подписи остаются читаемыми, а не уменьшаются вместе с картинкой.
  • Двойное касание ячейки протокола не приближает страницу (touch-action: manipulation).

12Администрирование: данные и словари

Сведения о детях относятся к закрытой документации специалиста. Приложение не имеет сервера и ничего не отправляет в сеть: данные лежат в локальной базе данных браузера (IndexedDB) на том компьютере, где введены. Этот компьютер находится у специалиста, в России, поэтому требование закона о хранении персональных данных граждан РФ в России выполняется без собственного сервера.

Раздел открывается значком базы данных в шапке и состоит из двух вкладок: «Данные» и «Словари».

Данные: локальная база

Все данные — группы, дети, контакты родителей, отметки, программы, библиотека упражнений и словари — хранятся в IndexedDB, встроенной базе данных браузера. Отметки каждого ребёнка лежат отдельной записью, поэтому правка балла записывает в базу несколько килобайт, а не всё целиком. Изменения сохраняются автоматически через четверть секунды после последней правки и сразу при закрытии вкладки. Данные, которые хранились в прежних версиях (до 1.5), при первом открытии переносятся в базу сами.

СведениеЧто означает
Занятосколько места база занимает в браузере; сотня детей — это сотни килобайт
Хранение«постоянное» — браузер не удалит базу при нехватке места. Если хранение не постоянное, кнопка «запросить постоянное» просит браузер об этом
Последняя копия в файлдата последней резервной копии; если копии нет больше недели, над страницами появляется напоминание

Защита паролем

Если за компьютером работает не только специалист, базу стоит зашифровать. «Включить защиту» задаёт пароль (не короче 8 символов), и все записи базы перешифровываются алгоритмом AES-256; ключ выводится из пароля (PBKDF2, 310 000 итераций) и существует только в памяти открытой вкладки. После этого:

  • при открытии приложения появляется экран входа — без пароля данные нечитаемы даже при прямом доступе к файлам браузера;
  • после простоя база блокируется сама — через 5, 15 (по умолчанию), 30 или 60 минут; заблокировать сразу можно значком замка в шапке;
  • резервная копия в файл тоже шифруется этим паролем;
  • пароль можно сменить или снять защиту — база перешифруется.

Пароль нигде не хранится, восстановить его нельзя. Если пароль забыт, данные расшифровать невозможно: экран входа предложит удалить зашифрованную базу и начать заново, а данные вернуть из резервной копии. Запишите пароль и храните его отдельно.

Шифрование работает только когда приложение открыто по защищённому адресу (https://) — так работает опубликованная версия. При открытии по незащищённому адресу приложение сообщает об этом вместо кнопки включения защиты.

Шапка, футер и версия

Шапка с меню закреплена сверху и остаётся на месте при прокрутке длинных таблиц и программ; на телефоне меню — одна строка с горизонтальной прокруткой, чтобы шапка не занимала пол-экрана. Футер закреплён снизу: слева — название и напоминание, что данные хранятся в этом браузере, справа мелким серым шрифтом — версия приложения (при наведении — дата сборки). При печати шапка и футер скрываются.

Версионность

Версия задаётся в package.json по правилам семантического версионирования (МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ) и при сборке подставляется в футер. Изменения каждой версии описаны в CHANGELOG.md. Выпуск новой версии — одна команда:

npm run release:patch исправления: 1.2.0 → 1.2.1 npm run release:minor новые возможности: 1.2.0 → 1.3.0 npm run release:major несовместимые изменения: 1.2.0 → 2.0.0

Команда поднимает версию, создаёт коммит и тег vX.Y.Z и отправляет их на GitHub. По тегу GitHub Actions создаёт релиз, а Vercel публикует новую сборку. Описание каждого релиза — изменения по сравнению с предыдущей версией: раздел CHANGELOG, список коммитов с прошлого тега и ссылка на полное сравнение версий. Перед выпуском в CHANGELOG добавляется раздел новой версии.
